# Écrire pour Kilakodon Services

1. **Chercher d'abord dans `docs/CONTENT.md`.** Si le texte y est, l'utiliser tel quel (adaptations de longueur seulement).
2. Sinon, écrire selon ces règles :
   - Français professionnel, vouvoiement, phrases courtes, **bénéfice d'abord**, vocabulaire du terrain (stock, caisse, boutique, FCFA, Mobile Money, connexion qui coupe).
   - Structure : problème reconnu → ce que ça change → prochaine action claire.
   - Titres : affirmation concrète ; au plus un fragment en `*italique*` pour l'accent rouge.
   - CTA : verbe d'action + objet (« Faire mon diagnostic gratuit », « Discuter sur WhatsApp »).
3. **Interdits absolus** : superlatifs invérifiables (« n°1 », « le meilleur », « zéro fraude »), chiffres sans source, clients, logos, témoignages ou résultats non autorisés, promesses de délai ferme, de prix, de conformité légale ou de disponibilité 24/7.
4. Toute information factuelle inconnue → `[À VALIDER : précision]`. Le contenu qui la contient reste en `draft` ; signaler la question dans `docs/DECISIONS.md` si elle est nouvelle.
5. SEO : title ≤ 60 caractères (+ « — Kilakodon Services »), meta description 140–160 caractères, une seule H1, mots-clés naturels (« logiciel de gestion », « Bamako », « Mali », le métier).
6. Ajouter tout nouveau texte durable dans `docs/CONTENT.md` (section adéquate) pour garder une source unique.
